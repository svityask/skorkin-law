# Сайт юриста Скоркина Игоря Валерьевича

Сайт-визитка в строгом стиле американских юридических фирм (Cravath, Wachtell, Sullivan & Cromwell) и админ-панель для редактирования без программиста.

## Концепция «очень дорого»

| Приём | Зачем |
|---|---|
| Палитра из 4 цветов: тёмно-синий `#0d1b2e`, бордо `#6e1c26` (в тон галстуку на фото), слоновая кость `#f6f2ea`, латунь `#a8895a` | Цвета старых денег: так выглядят Гарвард, частные банки, клубы |
| Антиква Cormorant Garamond для заголовков и тонкий гротеск Inter для текста | Классика и современность, по-русски выглядит благородно |
| Много воздуха, тонкие линии 1px, римская нумерация, надзаголовки капителью | Дорогое ничего не продаёт криком |
| Портрет в латунной рамке с отступом | Работает как паспарту в галерее |
| Цифры и обезличенные дела списком, без лишних эпитетов | Факты убеждают сильнее обещаний |
| Никаких стоковых иконок, шаблонных молоточков и весов, анимация только при плавном появлении блоков | Признаки дешёвых сайтов убраны |

| Печать с вращающейся надписью на портрете, крупный ч/б портрет с цитатой, зерно бумаги, мягкие появления | Детали, по которым узнаётся дорогая полиграфия |

Разделы: первый экран с портретом → цифры → направления практики → биография и образование → цитата с портретом → избранные дела → подход к работе → рейтинги → контакты и форма.

## Структура

```
index.html, styles.css, app.js   — сайт
content.json                     — весь текст сайта (его редактирует админка)
assets/portrait.jpg              — фотография (загружается через админку)
admin/                           — админ-панель (/admin/)
```

## Админ-панель

Откройте `/admin/`. Вход по fine-grained token GitHub:
1. https://github.com/settings/personal-access-tokens/new
2. Repository access: только репозиторий сайта. Permissions → Contents: **Read and write**.
3. Вставьте ключ на странице входа. Он сохраняется только в браузере.

Можно менять любые тексты, добавлять, удалять и переставлять направления, дела и цифры, загружать фото. Кнопка «Опубликовать» сохраняет изменения в репозиторий, и через 1–2 минуты GitHub Pages обновляет сайт.

Репозиторий и ветка задаются в `admin/config.js`.

## Публикация

GitHub Pages: Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save.

Сайт будет доступен по адресу https://svityask.github.io/skorkin-law/, админка — https://svityask.github.io/skorkin-law/admin/.

Свой домен (например, skorkin-law.ru): Settings → Pages → Custom domain, а у регистратора — CNAME на `svityask.github.io`.

## Персональные данные (152-ФЗ)

Сайт не собирает и не хранит персональные данные посетителей:
- формы обратной связи нет — посетитель звонит или пишет на почту напрямую;
- шрифты лежат в `assets/fonts/`, запросов к Google и другим сторонним сервисам нет;
- счётчиков и аналитики нет.

Если в будущем добавить форму заявки или Яндекс Метрику, понадобятся политика обработки персональных данных, согласие посетителя и хранение данных на серверах в России.
